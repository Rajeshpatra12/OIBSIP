# Online Reservation System

## Objective

Developed a Java Swing based Online Reservation System that allows users to log in, book train tickets, generate PNR numbers, retrieve reservation details, and cancel reservations using JDBC and SQLite.

## Technologies Used

* Java
* Java Swing
* JDBC
* SQLite
* OOP Concepts

## Features

* User Login Authentication
* Reservation Form
* Auto Train Name Population
* Unique PNR Generation
* JDBC Database Connectivity
* Reservation Storage
* Booking Confirmation Dialog
* Fetch Reservation by PNR
* Reservation Cancellation
* Input Validation
* SQL Injection Prevention using PreparedStatement

## How to Run

1. Download SQLite JDBC Driver.
2. Add JAR file to project libraries.
3. Run Main.java.
4. Login using default credentials.
5. Book and cancel reservations.
